# Агрегат пользователя

## Поля агрегата пользователя

|Название|Сырой тип данных|
|:---|:---|
|Идентификатор|uuid|
|Адрес электронной почты|string|
|Дата рождения|date|
|Статус|enum|
|Состояние|enum|
|Версия|integer|

Варианты статуса:

|Русский|Английский|
|:---|:---|
|администратор|admin|
|пользователь|user|

Варианты состояния:

|Русский|Английский|
|:---|:---|
|активный|active|
|заморожен|frozen|
|удален|deleted|

## Инварианты

1. Идентификатор должен быть уникальным.
1. Адрес электронной почты должен быть уникальным.
1. Дата рождения должна находится в диапазоне между 1900 годом и 6 годами назад
от настоящего дня.
1. Сменить адрес электронной почты, дату рождения может либо сам пользователь,
либо администратор.
1. Удалить пользователя может только он сам или администратор.
1. Удаленного пользователя нельзя редактировать.
1. Заморозить пользователя может только администратор.
1. Замороженного пользователя может активировать только администратор.
1. Замороженный пользователь не может ничего изменять, он может только
просматривать свои данные.
1. Пользователя можно только редактировать только если его состояние активно,
иначе ему можно изменить только состояние.
1. Редактировать других пользователей может только администратор.
