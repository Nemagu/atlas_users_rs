# Команды

Необходимые команды для изменения сервиса.

## Приватные команды

Список необходимых команд:

1. Публикация сообщения о создании пользователя. [ ]
1. Публикация сообщения об обновлении пользователя. [ ]
1. Публикация сообщения об удалении пользователя. [ ]

## Публичные команды

Список необходимых команд:

1. Подтверждения почты для создания пользователя. [ ]
1. Создание пользователя. [ ]
1. Вход пользователя через пароль. [ ]
1. Вход пользователя через одноразовый код. [ ]
1. Получение кода для смены пароля. [ ]
1. Смена пароля. [ ]
1. Получение кодов для смены электронной почты. [ ]
1. Смена электронной почты. [ ]
1. Смена даты рождения. [ ]
1. Назначение пользователя администратором. [ ]
1. Назначение пользователя обычным пользователем. [ ]
1. Заморозка пользователя. [ ]
1. Удаление пользователя. [ ]
