# Команды

Необходимые команды для изменения сервиса.

## Приватные команды

Список необходимых команд:

- [x] Публикация сообщений связанных с пользователями.

## Публичные команды

Список необходимых команд:

- [ ] Подтверждения почты для создания пользователя.
- [ ] Создание пользователя.
- [ ] Вход пользователя через пароль.
- [ ] Вход пользователя через одноразовый код.
- [ ] Получение кода для смены пароля.
- [ ] Смена пароля.
- [ ] Получение кодов для смены электронной почты.
- [ ] Смена электронной почты.
- [ ] Смена даты рождения.
- [ ] Назначение пользователя администратором.
- [ ] Назначение пользователя обычным пользователем.
- [ ] Заморозка пользователя.
- [ ] Удаление пользователя.
