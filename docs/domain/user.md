# Агрегат пользователя

## Поля агрегата пользователя

|Название|Название на английском|Сырой тип данных|
|:---|:---|:---|
|Идентификатор|UserId|uuid v7|
|Адрес электронной почты|Email|string|
|Статус|UserStatus|enum|
|Состояние|UserState/State|enum|
|Версия|Version|integer|

Варианты статуса:

|Русский|Английский|
|:---|:---|
|администратор|admin|
|пользователь|user|

Варианты состояния:

|Русский|Английский|
|:---|:---|
|активный|active|
|заморожен|frozen|
|удален|deleted|

## Инварианты агрегата пользователя

1. Идентификатор должен быть уникальным.
1. Адрес электронной почты должен быть уникальным.
1. Сменить адрес электронной почты может либо сам пользователь, либо администратор.
1. Удаленного пользователя нельзя редактировать.
1. Замороженного пользователя может активировать только администратор.
1. Пользователя можно только редактировать только если его состояние активно,
иначе ему можно изменить только состояние.
1. Редактировать других пользователей может только администратор.
1. Версия агрегата должна меняться только один раз в рамках одной транзакции,
если требуется его изменение.
