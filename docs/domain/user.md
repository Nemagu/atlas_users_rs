# Агрегат пользователя

## Поля агрегата пользователя

| Название поля |
|:---|
| Идентификатор |
| Адрес электронной почты |
| Статус |
| Состояние |
| Версия |

| Варианты значений статусов |
|:---|
| Администратор |
| Пользователь |

| Варианты значений состояния |
|:---|
| Активный |
| Заморожен |
| Удален |

## Инварианты агрегата пользователя

- Адрес электронной почты должен быть уникальным для всех пользователей
- Сменить адрес электронной почты может либо сам пользователь, либо администратор
- Удаленного пользователя нельзя редактировать
- Замороженного пользователя может активировать только администратор
- Пользователя можно только редактировать только если его состояние активно, иначе ему можно изменить только состояние
- Редактировать других пользователей может только администратор
- Версия агрегата должна меняться только один раз в рамках одной транзакции, если требуется его изменение
